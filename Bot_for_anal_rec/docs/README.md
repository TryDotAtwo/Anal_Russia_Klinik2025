## Документация проекта Bot_for_anal_rec

Эта папка служит **долговременной памятью агента** и местом, где фиксируются архитектура, решения, гипотезы, эксперименты и ход эволюции проекта.

- **`architecture.md`** — текущее устройство модулей, пакетов и данных, принципы разделения ответственности.
- **`agent-memory.md`** — ключевые факты, которые важно помнить агенту между сессиями (важные файлы, константы, правила работы).
- **`hypotheses.md`** — гипотезы по улучшению, результаты экспериментов и выводы.
- **`operations-log.md`** — журнал существенных изменений в коде и процессах (операционный лог).
- **`roadmap.md`** — краткий план развития проекта.

При каждом заметном изменении архитектуры или логики **обновляйте соответствующий файл**, чтобы сохранить контекст для будущих доработок.
