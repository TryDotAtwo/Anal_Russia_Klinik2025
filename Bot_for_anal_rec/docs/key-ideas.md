# Ключевые идеи (для агента)

## Два пайплайна упоминаний

1. **MEDIQ** (`Logic/mediq_match.py`)
   - Жёсткий: только **целое слово** (и склонения), не подстрока.
   - Пример: препарат «Онко» **не** матчится в слове «Онкология».
   - Многословные названия: последовательность целых слов в тексте (каждое в своей словоформе).
   - Вход: список поисковых названий (`search_names`), текст. Выход: список с `start`, `end`, `drug`, `source="mediq"`, `context`.

2. **Расстрельный список + слова-маркеры** (`Logic/blacklist_markers.py`)
   - Мягкий: **подстрока** — слово/словоформа может быть частью другого слова.
   - Ахо–Корасик по словоформам чёрного списка и по списку слов-маркеров (файл в `word_markers_path`, опционально).
   - Выход: список с `start`, `end`, `drug`, `source="blacklist"|"marker"`, `context`.

## Дедупликация

- `Logic/dedupe.py`: объединение результатов двух пайплайнов и **дедуп по позиции** `(start, end)`.
- Один и тот же препарат, найденный и в MEDIQ, и в расстрельном/маркерах на одной позиции → одно упоминание.

## Корень и конфиг

- В корне проекта только `Main.py` и пакеты (`core/`, `io/`, `cli/`, `Logic/`).
- Конфиг: `core/config.py` (`ANALYSIS_CONFIG`, `BATCH_SIZE`, опционально `word_markers_path`).

## Запуск

- Из папки проекта: `python Main.py` (или `python cli/main_cli.py`).
