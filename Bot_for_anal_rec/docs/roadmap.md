## Roadmap Bot_for_anal_rec

### Ближайшие шаги (1–2 итерации)

- Выделить модуль конфигурации (пути к данным, параметры батчей) из `Main.py`.
- Вынести высокоуровневые пайплайны анализа в отдельный модуль.
- Собрать все операции чтения/записи файлов в один `io`‑модуль.

### Среднесрочные шаги

- Структурировать папки кода в слои `core/`, `logic/`, `io/`, `cli/`.
- Оформить минимальный набор тестов для ключевой логики (проверка соответствия чёрному списку, корректность структуры JSON‑результатов).
- Добавить простой CLI‑интерфейс (аргументы командной строки: пути к данным, выбор режима анализа).

### Долгосрочные идеи

- Обернуть пайплайны в сервис (REST/gRPC) для удалённого вызова.
- Ввести версионирование схемы выходных JSON‑файлов и миграции.
- Добавить более сложные LLM‑сценарии (сравнение рекомендаций, агрегированные выводы и т.п.).
