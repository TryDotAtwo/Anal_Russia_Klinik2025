## Операционный лог изменений

Фиксируйте здесь существенные изменения в архитектуре, конфиге и поведении пайплайнов.

### Записи

- **Дата:** 2026‑03‑11  
  **Изменение:** добавлено единое дерево Ахо–Корасика для MEDIQ, расстрельного списка и слов‑маркеров; реализовано сохранение прогресса LLM‑анализа в `llm_progress.json`; очищен корень пакета от данных за счёт `.gitignore`; обогащён итоговый JSON.  
  **Детали:**
  - построение одного автомата по словоформам из `drugs.json` (MEDIQ‑поиск) и `blacklist_drugs.json` + слов‑маркеров, с разделением логики MEDIQ/blacklist/marker на этапе пост‑обработки;
  - LLM‑анализ выполняется батчами, прогресс (количество обработанных упоминаний) сохраняется в `llm_progress.json` и позволяет продолжить после обрыва;
  - `.gitignore` настроен так, чтобы на GitHub попадали только важные референсные данные (`drugs.json`, `blacklist_drugs.json`), а промежуточные JSON, логи и HTML в `Bot_for_anal_rec/` игнорировались;
  - итоговые файлы `Match_Clinick_batch_*.json` теперь содержат:
    - полную запись по препарату из `drugs.json` (в `additional_info[*].drug` и `kind`),
    - полную запись из `blacklist_drugs.json` для препаратов из расстрельного списка (`blacklist_entry`).  
  **Цель:** ускорить и унифицировать поиск упоминаний, сделать результаты самодостаточными для последующего анализа без обращения к внешним JSON, подготовить проект к публикации и официальному использованию.  
  **Затронутые файлы:** `Bot_for_anal_rec/Main.py`, `Bot_for_anal_rec/Logic/blacklist_markers.py`, `Bot_for_anal_rec/.gitignore`, `docs/data-notes.md`, `README.md`.
